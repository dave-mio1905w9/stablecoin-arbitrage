# stablecoin-arbitrage

I got tired of flipping between DEX tabs to check USDC/USDT, DAI/USDC, etc. This fetches on-chain prices via RPC and prints the best spreads.

## install

pip install -r requirements.txt

## usage

The --watch flag loops every 30 seconds. Ctrl-C to quit.
